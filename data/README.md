# Data

`sample_ticks.csv` is entirely synthetic, generated by `generate_orders.py` — a
random-walk mid price with orders clustered around it (mix of LIMIT/IOC/MARKET,
a pool of owner ids for self-cross testing). No real market data, no license
concerns.

Regenerate with:

```bash
python3 generate_orders.py --output sample_ticks.csv --orders 500000 --seed 42
```

`--seed` makes the output deterministic — same seed, same file, every time.
